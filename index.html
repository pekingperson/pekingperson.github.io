Research Assistant · Remote and onsite in Palo Alto, California · May–August 2026

Elorian.AI: Visual Reasoning & CAD Evaluation

  • LLM evaluation
  • Visual reasoning
  • API integration
  • CAD benchmarks

Evaluated visual reasoning and failure modes across open-source and proprietary LLMs, including Qwen, Kimi, OpenAI models, and Anthropic Claude Opus 5 and Fable 5. Implemented API-based evaluations and supported prompt-to-CAD workflows. Refined VQA audits and reference views for 43 CAD model packages, achieving a 100% pass rate in package validation.

Built a deterministic Python/OpenCV program that projects individual STEP solids into flat silhouettes and counts gear teeth from polar contours. Added component-name and geometric filters to reject non-gears, with numbered tooth images and structured reports for inspection.

Eliminated all false positives while correctly counting all gears in a 17-solid gearbox, and cut observed processing time from 49 to 22 seconds by filtering out non-gear parts based on their names and shapes. A geometry-only run recovered the same gear counts.

Follow-on project · September 2026

Gear Tooth Counting from Images

  • Python
  • OpenCV
  • Multi-view geometry
  • Focused evaluation

Expanded the August gear-counting tool to count teeth from images of 3D models, combining multiple views to handle gears that are partly hidden.

On a fixed 12-asset development set, obtained 11/12 exact counts (91.7%) for clean views and 11/12 after synthetic 90-degree contour masking. Both tested transmission ratios were exact (2/2). Evaluation used four local worker processes.

The remaining error was a low-resolution 56-tooth sprocket. These results describe the focused development set; the full benchmark was not run.
